# Potluck

> Potluck is free, open-source software (Apache-2.0) that puts a team's idle Macs and Linux machines to work: self-hosted GitHub Actions runners and sandboxes for coding agents, each job in a fresh VM or sandbox that is thrown away afterwards. It is made by Sengi.

Potluck is a program (`potluck`) for macOS and Linux. One machine runs a pool; friends and teammates join with a one-time code and lend machines to it. Work goes to a machine that is free, and a machine's owner can take it back at any time. There are no accounts: machines find each other over Tailscale (or a tunnel you set up).

- Install: `curl -fsSL https://raw.githubusercontent.com/sengirunners/potluck/main/install.sh | sh`
- Source, issues and documentation: https://github.com/sengirunners/potluck
- Releases: https://github.com/sengirunners/potluck/releases
